线路决定国内访问的延迟和晚高峰稳定性。ByteVirt 那条优化线把三网拆开走：电信 163 骨干从广州出口，联通 AS4837 经日本，移动 CMI 经香港。它的标准线没有这些处理，国内访问延迟明显更高。同一家厂商、同一个机房，两条线的体验差距就是这么大。
